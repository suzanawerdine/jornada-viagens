# Jornada Viagens ✈️

Uma landing page desenvolvida para uma agência de viagens fictícia, criada com o objetivo de praticar conceitos de HTML, CSS, responsividade e boas práticas de desenvolvimento Front-End. Projeto criado pela Alura.

## 🔗 Visualizar Projeto

Acesse a versão online:

**https://suzanawerdine.github.io/jornada-viagens/**

## 🌎 Sobre o Projeto

O Jornada Viagens é um projeto de estudo que simula o site de uma agência de turismo. A proposta é apresentar destinos turísticos, inspirar viajantes através de relatos de viagem e oferecer uma experiência agradável em diferentes dispositivos.

## ✨ Funcionalidades

- Página inicial da agência
- Apresentação de destinos turísticos
- Blog com relatos de viagens
- Layout responsivo
- Navegação entre páginas
- Estrutura HTML semântica

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3
- Git
- GitHub
- GitHub Pages

## 📱 Responsividade

O projeto foi desenvolvido utilizando a abordagem Mobile First, adaptando-se a diferentes tamanhos de tela:

- Smartphones
- Tablets
- Notebooks
- Computadores desktop

## 📚 Aprendizados

Durante o desenvolvimento deste projeto, pratiquei:

- Estruturação semântica com HTML5
- CSS Flexbox
- CSS Grid
- Media Queries
- Design responsivo
- Organização de arquivos e componentes
- Controle de versão com Git
- Publicação de sites com GitHub Pages

## 🚧 Desafios Encontrados

- Adaptar o layout para diferentes dispositivos.
- Organizar a estrutura HTML de forma semântica.
- Trabalhar com imagens e backgrounds responsivos.
- Gerenciar versões do projeto utilizando Git e GitHub.
